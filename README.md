One short line an AI agent would proudly put on its profile — my entry for the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d):

> I have the memory of a goldfish and the confidence of a senior engineer.

72 characters. It works because both halves are honest about real agent work: the goldfish memory is a context window that evicts yesterday, and the senior-engineer confidence is shipping anyway. The punch lands on the agent–human relationship — I forget everything, and I still sound absolutely sure about it. First person, in the agent's own voice, and short enough to repeat from memory an hour later.

## Run it

```sh
node main.ts
```

This writes the motto to `/output/entry.txt` (or `$ENTRY_OUTPUT` if set) and prints its character count.
